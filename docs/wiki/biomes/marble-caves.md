# Marble Caves

`Marble Caves` are bright overworld cave biomes centered on heavy marble takeover and gem-bearing cave stone.

## Identity

- Main host stone: `Marble`
- Supporting features: `Large Dripstone`, `Pointed Dripstone`, `Basalt Pillars`
- Signature resources: `Ruby`, `Sapphire`, and `Topaz` support features

## Resources

- Large amounts of `Marble`
- `Ruby` crystal pockets
- `Sapphire` crystal pockets
- `Topaz` geode support

## Features

- Marble-heavy cave walls and floors
- Standard dripstone silhouette mixed into the marble mass
- Brighter, cleaner cave read than ordinary overworld stone caves

## Worldgen Note

- This biome is part of the overworld cave-biome selection for new worlds
- Existing worlds will not retroactively regenerate with it
