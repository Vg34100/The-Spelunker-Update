# Crystal Caverns

`Crystal Caverns` is a true overworld cave biome focused on bright stone, crystal growth, and gem-rich cave systems.

## Identity

- Main host stone: `Marble`
- Secondary stone: `Calcite`
- Contrast: `Smooth Basalt`
- Accent block: `Prismatic Stone`

## Resources

- Elevated `Ruby` generation
- Elevated `Sapphire` generation
- Elevated `Topaz` generation
- Large amounts of `Marble`
- Unique `Prismatic Stone`

## Features

- Marble-heavy cavern regions
- Crystal-rich prismatic clusters
- Basalt ribs and columns
- Spike-heavy cave silhouette from dripstone-style generation
- Dark caves with localized glow pockets instead of full brightness

## Worldgen Note

- This biome is added to the overworld cave-biome selection for new worlds
- Existing worlds will not retroactively regenerate with it
