# Magma Vaults

`Magma Vaults` are deep overworld cave biomes built around cinder rock, ashen dirt, scorched dripstone, and heavy lava ambience.

## Identity

- Main host stone: `Cinder Rock`
- Secondary ground: `Ashen Dirt`
- Accent features: `Scorched Dripstone`, `Charred Bones`, and magma-heavy pockets

## Resources

- Large amounts of `Cinder Rock`
- `Ashen Dirt`
- `Charred Bones`
- `Scorched Dripstone`

## Features

- Dense lava-heavy cave atmosphere
- Ash particles and warm cave lighting
- Deep cave silhouette shaped by scorched dripstone clusters
- Strong industrial-volcanic palette compared to the brighter crystal and marble biomes

## Worldgen Note

- This biome is part of the overworld cave-biome selection for new worlds
- Existing worlds will not retroactively regenerate with it
