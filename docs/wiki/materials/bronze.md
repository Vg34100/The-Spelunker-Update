# Bronze

## Overview

Bronze is the first alloy added through the Spelunkery alloying system.

It is produced in the foundry using tin and copper ingots and is intended to become a utility-focused alloy for cave gear and expedition hardware.

## Production

- Produced in a `Foundry` placed directly above a filled `Crucible`
- First recipe:
  - `3 Copper Ingots`
  - `1 Tin Ingot`
  - consumes `1` crucible lava charge
  - yields `4 Bronze Ingots`

## Storage

- `Bronze Ingots` can be crafted into a `Block of Bronze`
- `Block of Bronze` can be crafted back into `9 Bronze Ingots`
- `Bronze Tiles` are available as a decorative crafted block
- `Bronze Lantern` is a warm metal light source

## Current Uses

- `Bronze Compass` reports your current depth
- `Bronze Shield` can bash attackers back if you brace into the hit
- `Bronze Lantern` provides decorative cave lighting
- `Bronze Bars` and `Bronze Chain` expand bronze into cave building hardware
- `Torch Launcher` uses bronze as its main crafted metal

## Gear Direction

- Bronze is the first material with a full general-purpose tool and armor set scaffolded for it
- The intended role is utility-first cave gear rather than endgame combat power

## Planned Uses

- Bronze cave instruments
- Utility components and expedition hardware
